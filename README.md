# www.sodhak.ai

Marketing site for SODHAK AI. Plain HTML and CSS: edit the files in `site/`. A push to `main` publishes the site through `.github/workflows/deploy.yml`.

- The app lives at https://app.sodhak.ai. The "Sign in" and "Start free trial" links point there.
- The source copy is kept in the AITracr repo under `website/`.
- Preview locally with `python3 -m http.server -d site 8000`.
