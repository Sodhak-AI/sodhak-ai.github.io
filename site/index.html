Platform

One place to find, watch and govern AI.

AI inventory

Discover models, agents and AI services across AWS Bedrock, Google Vertex AI and Microsoft Copilot Studio. Know what exists and who owns it.

Findings & detection rules

Every prompt and tool call is checked for secrets, personal data (PAN, Aadhaar, cards, emails), prompt injection and jailbreaks. Add your own rules and test them on a real event before turning them on.

AI Gateway

One key and one endpoint for every model provider, with OpenAI and Anthropic compatible APIs. Block or redact sensitive data before it leaves, track spend by key and model, and control which MCP tools agents can call.

Agent lifecycle

Register agents, move them from staging to production, run reviews and grant waivers. Unregistered or non-compliant agents show up straight away.

Logs, metrics & reports

Full activity history per user, tool and agent, built on OpenTelemetry. Schedule reports by email for security reviews and audits.

Actions

Block, redact, alert or ask the user to justify. Send findings to Slack, your SIEM over syslog, or any webhook.

How it works

Live in an afternoon.

  1. 1

    Connect

    Point AI tools at SODHAK with OpenTelemetry, Claude Code hooks, the browser extension, the desktop agent or the AI Gateway. Connect cloud accounts for inventory.

  2. 2

    Detect

    Events are normalised and checked against built-in and custom rules as they arrive. Findings show who, which tool, and exactly what was sent.

  3. 3

    Act

    Block risky prompts before they reach the model, alert the right people, and give auditors a report instead of a spreadsheet.
